## Key technical details for next session

### Kit API quirks (verified this session)

- `POST /v4/subscribers` ignores `tag_names` silently — must use `POST /v4/tags/{id}/subscribers` separately
- Sequence email creation uses `content` param, NOT `body` (`body` is silently accepted but not stored)
- Sequence email GET list view returns `content: null` — use individual GET `GET /v4/sequences/{id}/emails/{email_id}` to verify content exists
- Kit returns 200, 201, or 202 for subscriber create/update (not always 201; no 409 like Beehiiv)
- Subscriber DELETE returns 404 — likely invalid endpoint path, not plan restriction (404 ≠ 403)
- API-created subscribers do NOT fire Kit's native "signup" trigger — use "Tag added" trigger for automations

## Machine
- Kali Linux 2026.1, kernel 6.18.12+kali-amd64

- This is a daily-driver WORKSTATION that also runs a dev stack (podman containers: memgraph, qdrant; system ollama), Sunshine game-streaming, Discord, and is used for security work. Dual-boot with Windows (Windows Boot Manager on the EFI partition).

## The crash being fixed
Game: 007 First Light (Steam AppID 3768760), runs as a Windows .exe under Proton (Vulkan).
Symptom: freezes ~4s into intro, audio continues ~30s, then hard crash/quit.

Confirmed root-cause evidence from kernel logs (3 separate crashes), e.g.:
```
20:09:07 x86/split lock detection: #AC: 007FirstLight.e took a split_lock trap
20:09:13 x86/split lock detection: #AC: 007FirstLight.e took a split_lock trap   (storm of ~27 traps)
20:09:25 NVRM: Xid (PCI:0000:01:00): 109, name=007FirstLight.e, errorString CTX SWITCH TIMEOUT
```
Hypothesis: 12th-gen split-lock detection traps the game's unaligned atomics → kernel stalls those threads → GPU submission thread starves → Xid 109 GPU context-switch timeout → freeze → crash. This is the documented Alder Lake + Linux gaming bug.

Secondary findings (ruled out / handled): zero swap + daily OOM kills (fixed with swap); a Toshiba USB3 drive resetting (user unplugged it); GPU/RAM contention from Sunshine NVENC + ~12 Chrome + overlays (stopped).

### 1. Swap (was 0 swap, OOM-killing daily)
- Created `/swapfile`, 32GB, perms `-rw-------` root, via `fallocate -l 32G` + `mkswap` + `swapon`.
- `/etc/fstab` line added: `/swapfile none swap sw 0 0`
- Old stale fstab line (commented) referenced a swap partition that is now an NTFS partition.

```

```
(All three live now. split_lock_mitigate=0 alone did NOT stop the traps — that's why GRUB change below.)

After:  `GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nvidia-drm.modeset=1 nvidia-drm.fbdev=1 nvidia-modeset.hdmi_deepcolor=0 ibt=off split_lock_detect=off"`
Ran `sudo update-grub`. Verified `split_lock_detect=off` appears 2x in /boot/grub/grub.cfg. Backed up /etc/default/grub first.

### 4. gaming-mode toggle script (/home/deploy/.local/bin/gaming-mode), chmod +x
```bash
#!/usr/bin/env bash
set -uo pipefail

WATCHDOG=claude-watchdog-daemon.service
note() { printf '  %s\n' "$*"; }
cmd="${1:-status}"
case "$cmd" in
  on)
    systemctl --user stop "$WATCHDOG" 2>/dev/null && note "paused $WATCHDOG"
    for s in "${USER_SERVICES[@]}"; do systemctl --user stop "$s" 2>/dev/null && note "stopped $s"; done
    sudo systemctl stop ollama 2>/dev/null && note "stopped ollama (system)"
    pkill -f '/opt/google/chrome/chrome' 2>/dev/null && note "closed stray Chrome" || true
    free -h | awk '/Mem|Swap/{print "  "$0}'
    nvidia-smi --query-gpu=memory.used,utilization.gpu,temperature.gpu --format=csv,noheader ;;
  off)
    sudo systemctl start ollama 2>/dev/null && note "started ollama"
    for s in "${USER_SERVICES[@]}"; do systemctl --user start "$s" 2>/dev/null && note "started $s"; done
    systemctl --user start "$WATCHDOG" 2>/dev/null && note "resumed $WATCHDOG" ;;
  status) ... ;;
esac
```
